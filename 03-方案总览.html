PRODUCT & IMPLEMENTATION OVERVIEW

双声播客工坊 DuoCast · v3.0

面向 Windows 本地单用户的双人播客视频制作工作台。五个阶段：创建本期 → 编辑对话 → 试听配音 → 预览画面 → 生成导出；三个默认确认点：脚本、配音、样片。工程与成片保存在本机，文本与图片请求发送到所选 API，语音本地合成（默认）或 MiniMax，口型视频本地生成。样本数时间权威 + 版本驱动局部重跑，完整成片 ≤5 分钟。

版本 v3.0依据：04-详细优化方案.md载体：本地 SPA运行：Windows 本地 5 阶段 + 3 独立入口3 个默认确认点时长上限 5 分钟
单一权威原则：本文件是从 01 / 02 同步内容的可视化速览，不维护独立的算法定义；同一规则（时长口径、失效矩阵、确认策略）的权威定义在 04 及其指向的 01 / 02 章节。

0产品定义与核心机制

0.1 定位与 v2.1 差异

一句话面向 Windows 本地单用户的双人播客视频制作工作台，编排五个阶段，底层为文本 / 图片 API 适配器、本地语音（默认）或 MiniMax、本地 ComfyUI 口型视频与 ffmpeg 后处理
用户单人创作者（同时是操作者），无登录、无多用户、无账号体系
产出≤5 分钟（含片头片尾与首尾停顿）的双人对谈视频；横屏 16:9 默认，竖屏版式导出可选
数据边界工程与成片保存在本机；文本与图片请求发送到所选 API；MiniMax 启用时发送相应语音输入；其余处理全部本地。不再承诺「全程数据不出本机」
核心角色A / B 两位角色均可替换；角色资产（形象、性格描述、声音绑定）可跨期复用
形态单页应用，页内视图切换（非路由跳转）；左阶段轨 + 中央主视图 + 右检查器 + 底部时间轨
对话约束一句一个说话人；首版不开放同时说话或抢话
与 v2.1 方案的关键差异
维度v2.1（旧）v3.0（本方案）
页面结构P0–P9 十步五阶段 + 独立资产库 / 服务设置 / 任务中心；角色库不再是每期必经
确认关卡6 个 CP3 个默认确认点（脚本 / 配音 / 样片）+ 3 个可选（角色 / 构图 / 镜头，默认关闭）

数据边界全程不出本机文本 / 图片走所选 API，工程与成片本地；移除本地 LLM 与本地图像模型部署

0.2 三个核心机制

机制一 · 版本驱动的可调性

编辑产生草稿，生成产生候选，「采用」更新当前使用版本；页面状态由产物版本与任务状态推导，不手写完成标记。

能力说明UI 体现
局部重跑只重跑受影响的最小单元，按重跑矩阵传播改一句 → 只重合成该句所在合成单元；改裁切 → 只重跑镜头后处理，不触发 TTS 与基础视频
草稿 / 候选 / 已用三种版本身份显式区分产物卡片版本徽章；新候选默认不覆盖已用版本
版本可对比保留历史版本，并排对比后采用版本选择器 + 「对比」模式
过期提示上游采用新版本后，下游标「已过期」（仍可播放 / 查看）橙色「已过期」角标 + 显示其依赖的上游版本
快照隔离生成任务冻结输入快照；后台运行中编辑不干扰任务卡片显示「生成中 · 基于版本 R7」
重跑矩阵（页面语义摘要）：改台词实际读法 → 对应单元 + 后续偏移 + 变化区间；只改字幕标点 → 仅字幕版本；改显式发言间隔 → 仅重排时间轨；改数字推拉 / 裁切 → 仅后处理。权威定义见 02 §5.9，04 §重跑矩阵同源。
机制二 · 确认点（Approval）

确认是「对明确的输入版本与规格的接受」，不是全局布尔值。三个默认确认点 + 三个可选关卡。

确认点挂载位置默认确认内容记录字段
脚本阶段②末开话轮内容、说话人分配、预计时长脚本版本 ID
配音阶段③末开音色、读音、停顿、总时长 ≤300s音轨版本 ID + 总时长
样片阶段④末开口型、身份、边界连续、耗时可接受样片资产 ID + 工作流版本 + 规格区间
角色阶段①内关角色形象与声音绑定各绑定版本
构图阶段④内关同框底图与人物区域视觉变体版本
镜头阶段④内关镜头计划镜头计划版本
关键设计：每个确认点可配置为「必须确认 / 自动通过 / 跳过」，配置存于工程（节目模板可预置）。自动模式只在开启的确认点暂停；打回必须选择原因指向（脚本 / 配音 / 构图），用于导航回对应阶段。
机制三 · 分层参数
层内容入口
基础时长偏好、比例、角色、风格、镜头预设各阶段主视图
节目预设模板保存的对话风格、场景、声音绑定、镜头风格、导出规格、确认策略工程首页「节目模板」
高级引擎参数、采样、种子、编码、混用语音引擎入口检查器「高级」折叠区（默认收起）

4阶段② · 编辑对话

页面目标：以自然话轮为单位编辑对话，配选区改写与读音词典，产出确认的脚本版本。确认点：脚本。详见 01 §4。

操作成功结果与约束
编辑台词自动保存新草稿；已有配音保持可听，并标明「不对应当前文字」
增删、拖动发言更新顺序；稳定 ID（T07）不随显示序号改变
切换说话人更新声音绑定与合成单元划分；列出发言 ID 显示涉及哪些现有配音

精简至目标时长先给出删减建议，接受后才更新；配音后仍以实长再次检查
读音词典维护专名、数字、缩写读法；显示文本与朗读文本分别保存（displayText / spokenText）
确认脚本绑定当前脚本版本；通过后可自动启动配音（可在模板关闭）
技术分层对用户的呈现：句子（Line）、发言（Turn）、合成单元（Unit）三层在数据层存在；用户默认编辑自然的话轮（Turn），句子与单元由系统派生。质量提示采用具体问题措辞；语义判断由文本 API 提供建议并标注「AI 建议」。

页面目标：绑定音色并试听 → 按合成单元生成整期配音 → 校正读音与停顿 → 确认真实总时长。确认点：配音。详见 01 §5。

4关键算法速查

本节为索引：算法的权威定义全部在 02 §5（与 04 同源），本文件不维护独立副本，只给一句话摘要供速览。
算法一句话摘要权威定义
三层对象与单元划分句 / 发言 / 合成单元三层；按说话人、提供方、音色、情绪、语速、显式停顿、长度上限拆分02 §5.1

建轨算法48kHz PCM 母轨、整数样本偏移；权威时长 T = N / sampleRate（N = 最终音轨样本数，不是时间码推算）02 §5.3
对齐顺序与质量提供方时间信息优先且需与 spokenText 匹配校验；不可靠转本地对齐；时间戳视为候选标注02 §5.4
双轨视频适配业务层保证等长双轨；官方 add 实为串行拼接，工作流适配层负责时序正确，不重排用户台词迁就串接02 §5.5
三区间分段每段 outputRange（保留）/ renderRange（实际生成）/ contextRange（续接上下文）；改镜头不重跑基础视频02 §5.6
帧数与最终时长帧数由样本区间与帧率推导；整片视频与母轨长度误差 < 一个输出帧02 §5.7
后处理顺序基础视频 → 保留区间 → 镜头裁切与版式 → 可选补帧 → 可选烧录字幕 → 合并权威音轨 → 编码 → 校验02 §5.8
缓存、版本与重跑产物不可变版本路径 + 依赖哈希；重跑矩阵精确传播，最小化重复推理与重复计费02 §5.9
重跑矩阵（摘要）：改台词实际读法 → 对应单元 + 后续偏移 + 变化区间；只改字幕标点 → 仅字幕版本；改显式发言间隔 → 仅重排；改声音 → 该角色全部单元；改底图 / 人物区域 → 对应视觉版本的段；改数字推拉 / 裁切 → 仅后处理。完整矩阵见 02 §5.9 与 04。

5性能预算

总耗时 ≈ 文本API耗时 + TTS耗时 + 图片API耗时 + 视频推理耗时 + 后处理耗时

视频倍率 R = 实际视频推理墙钟时间 / 实际生成的视频秒数
  R=10 → 300 秒纯推理量 ≈ 50 分钟
  R=20 → 300 秒纯推理量 ≈ 100 分钟
  （计算示例，不是 RTX 5080 测速结果；未含重叠与模型加载）
原则：不把未实测的分钟数写成承诺。工作台显示依据本机同规格样本计算的区间；没有测速数据时显示「尚未测定」。性能记录要求（冷/热启动、墙钟、峰值显存等）见 02 §9.2。

7路线图

交付关口制（02 §11）：旧九周计划不作为当前承诺；排期在阶段 A 后按实测重新估算。阶段 A 未通过前不先做完全部页面。

阶段交付物进入下一阶段的条件
A · 工作流验证双轨适配检查（无 GPU 契约测试）、短样片、30–60 秒跨段样片、硬件实测记录正确驱动双方；分段不丢时间；质量和耗时可评估
B · 最小生产闭环已有脚本 → 本地 / MiniMax 音频 → 上传底图 → 视频 → 导出至少一条接近 5 分钟的完整片通过验收；失败恢复有效
C · 内容与图片 API提纲与对话、局部改写、角色与场景 API、资产复用两类 API 失败不丢工作；同框图可生成或可替换上传
D · 五阶段编辑工作台全流程页面、时间轨、镜头、版本与影响提示局部修改不会无意义重跑整个工程
E · 自动执行与交付模板、确认点、后台恢复、启动器、字幕和竖屏版式用同一模板连续制作多期，操作与产物一致
关键要求：任务快照、产物哈希与持久化从阶段 B 开始实现；五分钟测试覆盖真实多话轮与至少一次长片中途恢复；首次工作流验证覆盖数字、英文缩写、短追问、长发言、A→B→A、B 开场、停顿、片尾。

8验收标准

功能验收（摘要，完整用例见 02 §12.1）
验收项最低通过标准
双轨时序A→B→A 与 B 开场均正确；视频条件不二次拼接或翻倍
发言参数单独修改语速、情绪、停顿有可听见且范围准确的结果
声音来源切换本地与 MiniMax 结果进入同一时间轨和视频管线，已有资产保留
五分钟限制超上限时可精简，无截断尾句
音画时间整片视频与母轨长度误差 < 一个输出帧
局部重跑改裁切不触发 TTS / 基础视频；改一句仅重合成相关单元并正确传播
中断恢复关闭页面、重启编排、单段失败、下载失败都可恢复且不丢有效结果
横竖屏横屏无拉伸；竖屏版式不误切另一位角色、不遮挡关键字幕
质量验收（02 §12.2）
  • 口型与身份质量先使用人工检查，不凭单一自动评分宣布通过
  • 接近五分钟的测试需完整观看，不能只看开头和结尾
  • 样片验收项：错误开口、口型同步、角色一致、边界连续、声音与清晰度
