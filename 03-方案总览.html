双声播客工坊 DuoCast · v2.0

面向 Windows 本地部署的双人播客视频生产工作台。八步流程：角色库 → 内容输入 → 分角脚本 → 配音锁轨 → 视觉设定 → 镜头表 → 试镜 → 渲染导出。音频先行锁定时间轨，图生图融合出唯一首帧，切镜 + 数字运镜，三级模式：手动可调 → 确认关卡 → 一键生成。

版本 v2.0载体：本地 SPA运行：Windows 本地 前端：React + TS + Vite + Tailwind后端：FastAPI + ComfyUI 9 个视图 · 6 个确认关卡

0产品定义与核心机制

0.1 定位与 v1.0 差异

一句话面向本地部署的双人播客视频生产工作台，编排八步流程，底层调用本机 ComfyUI 与 ffmpeg，数据不出本机
用户单人创作者，无登录、无多用户、无云端
产出≤10 分钟（默认 1–3 分钟）双人对谈视频，固定机位 + 切镜 + 轻微推拉
核心角色A 主持人固定音色与形象，跨期复用　B 嘉宾每期可变（人 / 拟人动物 / 拟人物件）
隐私仅访问 127.0.0.1，图片音频视频全部落在本地工程目录
与 v1.0 的关键差异
维度v1.0（旧）v2.0（本方案）原因
流程顺序场景 → 角色 → 遮罩 → 音色 → 文案 → 试镜 → 成片角色库 → 内容 → 分角 → 配音锁轨 → 视觉 → 镜头 → 试镜 → 成片音频先行才能锁定时间轨，时间轨是所有画面工作的坐标系
时间轨来源前端按 4.2 字/秒估算TTS 实际输出 + ASR 回填时间码估算值偏差 10%+，会导致切点错位
底图生成角色图 + 场景图 → 合成（贴图）图生图融合：角色设定图 + 场景图 → 模型重新生成「两人已在场景中」的同框底图贴图会导致光照/透视/景深不匹配，且错误会放大到整片
遮罩手动笔刷涂抹自动生成（左右站位 + bbox 校正），手涂降级为精修InfiniteTalk 多人物分支默认就是左右半幅 mask
说话人绑定遮罩 + 双轨add 模式零音频填充 + mask 跨注意力分配不说话的说话人收到全零音频特征，自然保持安静
镜头语言分镜（同框/单拍/单拍）切镜点 + 数字运镜（推/拉/裁切），不做摇镜播客语境下摇镜不真实；数字运镜零漂移、零额外算力
语音合成粒度逐句按说话人整段合成，ASR 回填句级时间码整段合成音色更稳；回填后仍保留句级重录能力
模式单一手动手动可调 → 确认关卡 → 一键生成用户要求的演进路径

机制二 · 确认关卡（Checkpoint）

把「需要人眼判断」的环节从流程里拎出来，做成显式暂停点。每个关卡可配置为 必须确认 / 自动通过 / 跳过，配置保存在工程里。

关卡名称确认内容通过条件
CP-1角色确认A/B 的形象图 + 音色两角色各有形象图 + 参考音且试听通过
CP-2稿件确认分角结果：说话人分配、口语化、总时长≥1 句台词且总时长在目标范围
CP-3底图确认两人站位、构图、风格、光照底图已生成且两人左右分居
CP-4配音确认音色、语气、语速、停顿、总时长A/B 两条整段音频已合成且试听通过
CP-5镜头确认切镜点、镜头类型、数字运镜所有镜头段已配置
CP-6试镜确认5 秒样片四项验收四项全勾
编号说明：CP 编号按「确认内容」分组，执行顺序为 CP-1 → CP-2 → CP-3 → CP-4 → CP-5 → CP-6（P4 配音之后是 CP-3 底图确认，P5 底图之后是 CP-4 配音确认）。编号一旦分配不再变动，避免与工程文件、日志中的引用冲突。
关键设计：关卡不是「锁」，是「暂停点」。两种工作方式：交互式（跑到关卡停下等操作）与前置式（开始前先把能提前定的素材锁定，跑到时自动通过）。
机制三 · 一键生成（Auto Mode）
输入一个话题，或一篇完整文章
前置资产角色 A（形象 + 音色，锁定）；角色 B（从库中选或新建）
自动执行内容 → 分角 → 配音 → 视觉 → 镜头 → 试镜 → 渲染 → 导出
中途停顿仅在用户勾选的确认关卡处暂停
失败处理停在失败步，保留已完成产物，可「从失败步继续」
产物与手动模式完全一致，保留每一步中间产物，可事后回到任意步微调
演进路径：① 手动调节打磨每一个环节 → ② 把需人工确认的环节拎出来做前置设定或中途确认 → ③ 打磨完成后收敛为一键生成。

       spk_audio_prompt = 角色参考音,
       text             = seg.text,
       emo_vector       = 角色情绪向量 ⊕ 该段语气映射,   # 8 维

   A_track = 在 T 坐标系里，A 的每句放在其 [start,end]，其余补零
   B_track = 同理
   assert len(A_track) == len(B_track) == T   # add 模式前置条件

5. 混音
   mix = A_track + B_track（脚本保证不抢话，故不会削顶）

6. 写入工程

4.2 数字运镜：ffmpeg 滤镜链
def build_filter(shot, out_w, out_h, fps):
    x, y, w, h = shot.crop
    parts = []
    if shot.type != 'wide':
        parts.append(f"crop=w={w}:h={h}:x={x}:y={y}")
        parts.append(f"scale={out_w}:{out_h}")
    if shot.camera.move != 'static':
        strength = shot.camera.strength
        frames = int((shot.end - shot.start) * fps)
        easing = EASING[shot.camera.easing]
        if shot.camera.move in ('pushIn', 'pushPan'):
            z = f"1+{strength}*{easing}(on/{frames})"
        elif shot.camera.move == 'pullOut':
            z = f"{1+strength}-{strength}*{easing}(on/{frames})"
        else:
            z = "1"
        parts.append(
            f"zoompan=z='{z}':d=1:"
            f"x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':"
            f"s={out_w}x{out_h}:fps={fps}"
        )
    return ",".join(parts) if parts else "null"
注意：zoompan 会引入抖动。建议先放大到 2× 再 zoompan，最后缩小，或用 scale + crop 组合替代。这是需要实测调优的点。
4.3 分段渲染与拼接
1. 分段：优先在镜头段边界切分；超长则按 segLength 均分
