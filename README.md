# 双声播客工坊 DuoCast

面向 **Windows 本地单用户**的双人播客视频制作工作台方案文档。

一句话：从「一个话题、一篇文章或一份已有脚本」出发，产出「一段 ≤5 分钟的双人对谈视频」；工程与成片保存在本机，文本与图片请求发送到所选 API，语音本地合成（默认）或 MiniMax，口型视频本地生成。

---

## 方案核心（v3.0）

### 五个主阶段

```
① 创建本期 ──▶ ② 编辑对话 ──▶ ③ 试听配音 ──▶ ④ 预览画面 ──▶ ⑤ 生成导出
   话题/文章/已有脚本     话轮级编辑       三层合成单元      构图/镜头/样片    分段渲染与导出
```

| 阶段 | 核心产出 | 关键点 |
|---|---|---|
| ① 创建本期 | 节目参数 + 内容输入 | 话题 / 文章 / 已有脚本三种入口；时长「根据内容，最多 5 分钟」；横屏默认、竖屏可选 |
| ② 编辑对话 | 结构化话轮（脚本版本） | 先内容结构、再直接生成双人对话；选区改写、读音词典；**确认点：脚本** |
| ③ 试听配音 | 权威音轨（版本化） | 句子 / 发言 / 合成单元三层；本地 TTS 默认、MiniMax 可选；**确认点：配音** |
| ④ 预览画面 | 同框底图 + 人物区域 + 样片 | 构图 / 镜头 / 样片三区；图片 API 生成或上传；**确认点：样片** |
| ⑤ 生成导出 | 成片 + 音频 + 字幕 | 分段渲染、暂停/取消/恢复、局部重跑、MP4/WAV/SRT 导出 |

资产库（角色与素材）、服务设置（四块）、任务中心为**独立入口**，不属于五个阶段。

### 三个默认确认点

| 确认点 | 挂载位置 | 确认内容 |
|---|---|---|
| 脚本 | 阶段②末 | 话轮内容、说话人分配、预计时长 |
| 配音 | 阶段③末 | 音色、读音、停顿、真实总时长 ≤300 秒 |
| 样片 | 阶段④末 | 口型、身份、边界连续性、耗时可接受 |

角色、构图、镜头确认为**可选关卡**（默认关闭，可在高级设置打开）。确认记录绑定的输入版本与规格，不只是全局布尔值。

### 页面状态模型

每个阶段的状态由其需要的**产物版本与任务状态**推导：未准备 / 可执行 / 执行中 / 待确认 / 已就绪 / 已过期 / 失败。编辑产生草稿，生成产生候选，用户「采用」后更新当前使用版本；后台任务完成时不覆盖已变化的新草稿。

### 与 v2.1 方案的关键差异

| 维度 | v2.1 | v3.0 |
|---|---|---|
| 页面结构 | P0–P9 十步 | **五阶段 + 独立资产库 / 服务设置 / 任务中心** |
| 确认关卡 | 6 个 CP | **3 个默认确认点** + 3 个可选关卡 |
| 时长上限 | ≤10 分钟 | **≤5 分钟（300 秒，含片头片尾与首尾停顿）** |
| 数据边界 | 全程不出本机 | **工程与成片在本机；文本 / 图片走所选 API；语音本地默认 + MiniMax 可选；视频本地** |
| 文本生成 | 本地 LLM（Ollama） | **通用文本 API 适配器**（不部署本地文本模型） |
| 图片生成 | 本地 Qwen-Image-Edit | **图片 API 适配器**（不部署本地图像模型） |
| 稿件流程 | 散文稿 → 分角 | **先内容结构、再直接生成双人对话**（两次生成） |
| 合成粒度 | 说话人连续段（run） | **句子 / 发言 / 合成单元三层**，按情绪、语速、显式停顿、长度上限拆分 |
| 停顿模型 | pre + post 双重编辑 | **单一 `transitionGapMs`** + 首尾 `leadInMs` / `tailOutMs` |
| 时间轨权威 | 最后一句时间码 | **最终 PCM 音轨样本数**（48kHz 母轨、整数样本偏移） |
| 双轨输入 | 等长双轨 + 固定 `add` | **业务层等长双轨 + 工作流适配层**（官方 `add` 是串行拼接，不能直接用） |
| 镜头与分段 | 切镜影响分段 | **解耦**：三个区间（output / render / context），改镜头不重跑基础视频 |
| 试镜 | 5 秒样片 | **首次工作流验证与每期 10–20 秒代表区间验证分开** |
| 页面状态 | done / stale 布尔 | **产物版本 + 任务状态七态** |
| 参数暴露 | 全暴露 | **基础 / 节目预设 / 高级三层** |

## 技术选型（摘要）

| 层 | 选型 |
|---|---|
| 前端 | React 18 + TypeScript + Vite + Tailwind CSS + Zustand + TanStack Query（沿用，不重选框架） |
| 可视化 | WaveSurfer.js（时间轨）、Konva（人物区域标注）、dnd-kit（排序） |
| 后端 | Python 3.11 + FastAPI + WebSocket + 进程内任务调度（GPU / API / CPU 三类队列） |
| 文本 | 通用文本 API 适配器（一套实际可用实现，可换提供方） |
| 图片 | 图片 API 适配器（分开登记文生图 / 单图编辑 / 多参考图编辑等能力） |
| 语音 | 统一 TTS 接口：**本地引擎默认**（ComfyUI 或隔离进程）+ **MiniMax 适配器**（系统音色 / 已有 voice_id） |
| 视频 | 本地 ComfyUI 对口型工作流（双轨时序适配层待验证） |
| 后处理 | ffmpeg（拼接 / 镜头 / 音画合并 / 字幕烧录）；RIFE 补帧**默认关闭** |
| 对齐 | faster-whisper（或 WhisperX 强制对齐）；优先使用提供方时间信息 |
| 数据存储 | 无数据库，工程 = 一个文件夹（`project.json` + revisions + assets + jobs） |

## 三条必须记住的技术事实

> 以下为 04 方案文档核对源码 / 官方文档的结果；联调时仍须按实际版本复核。

1. **InfiniteTalk 的 `add` 是串行拼接**，不是「已对齐双轨直接相加」。业务层统一等长时间轨后，必须由工作流适配层保证不二次拼接（[官方脚本](https://github.com/MeiGen-AI/InfiniteTalk)、[ComfyUI 节点](https://github.com/comfyanonymous/ComfyUI)）。
2. **InfiniteTalk 多人物模式默认 mask 是画面左右各半**，未提供 bbox 时硬切左右半幅；人物区域决定驱动绑定，但不保证听者绝对静止（允许眨眼与轻微动作）。
3. **时间权威是 PCM 样本数**：节目总时长 T = N / sampleRate（N = 首尾样本 + 全部单元样本 + 全部显式间隔样本）；句级位置 = 单元局部位置 + 整数样本偏移。采样率转换不能当作音质提升。

## 已知风险（开工前必读）

| # | 风险 | 影响 | 验证时机 |
|---|---|---|---|
| **R1** | 双轨时序适配：现有 ComfyUI 节点不满足「已对齐双轨」输入 | 视频侧接口不成立 | **阶段 A**（无 GPU 契约检查 + 短样片） |
| **R2** | 16 GB 显存跑 480p 双人口型视频过慢或跑不起来 | 耗时不可接受 | **阶段 A** |
| R3 | 分段边界姿态跳变 / 双脸 | 成片不可用 | 阶段 A（跨段样片） |
| R4 | 长片颜色漂移（官方已知） | 后半段偏色 | 阶段 B（接近 5 分钟完整片） |
| R5 | 图片 API 多参考图能力不达预期 | 同框底图需改走上传替代 | 阶段 C |

> **实施顺序约束**：阶段 A（工作流验证）未通过前，不先做完全部页面；替代形式（双窗 / 单人动态 + 静态全景 / 静态画面 + 配音）只做候选，主路径实测不达标后再对比选择。

## 开发路线（交付关口制）

| 阶段 | 交付物 | 进入下一阶段的条件 |
|---|---|---|
| A · 工作流验证 | 双轨适配检查、短样片、跨段样片、硬件实测记录 | 正确驱动双方、分段不丢时间、质量与耗时可评估 |
| B · 最小生产闭环 | 已有脚本 → 音频 → 上传底图 → 视频 → 导出 | 一条接近 5 分钟的完整片通过验收；失败恢复有效 |
| C · 内容与图片 API | 提纲与对话、局部改写、角色与场景 API、资产复用 | API 失败不丢工作；同框图可生成或可上传替代 |
| D · 五阶段编辑工作台 | 全流程页面、时间轨、镜头、版本与影响提示 | 局部修改不会无意义重跑整个工程 |
| E · 自动执行与交付 | 模板、确认点、后台恢复、启动器、字幕与竖屏版式 | 同一模板连续制作多期，操作与产物一致 |

> 旧九周计划不作为当前承诺；排期在阶段 A 后按实测重新估算。

## 本地运行

```bash
# 后端（端口 8100，可经 DUOCAST_PORT 覆盖）
cd apps/server
python -m uvicorn duocast.main:app --host 127.0.0.1 --port 8100

# 前端开发（端口 5178，/api 代理到 8100）
cd apps/web
pnpm install
pnpm dev

# 前端构建（构建后由后端直接托管 dist）
pnpm build
```

冒烟验证：`python apps/server/smoke_e2e.py`（需后端已启动）。

## 明确不做（首版边界）

- ❌ 多人（>2）对话、同时说话 / 抢话
- ❌ 本地文本模型、本地图像生成 / 编辑模型（用 API 适配器）
- ❌ 多用户、账号体系、云端渲染
- ❌ 实时预览（渲染均为离线）
- ❌ 未经验证的原生竖屏高规格动态（竖屏版式导出可用）
- ❌ 默认补帧、花字、复杂片头包装
- ❌ 多语言翻译配音、跨机器分布式渲染
