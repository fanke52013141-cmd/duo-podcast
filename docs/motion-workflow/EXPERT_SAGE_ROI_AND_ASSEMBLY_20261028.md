# Sage区域路径与采用窗口整期合成

日期：2026-10-28。本次是代码集成与无模型验收；尚未启用线上执行器，未登记新的角色成片质量通过。

## Sage＋区域执行

`ExpertMotionVideoProvider`支持显式配置`expert-sage-roi-v1`，固定整期共同裁切范围，保留原始像素尺度、绝对时间和完整语音上下文。仅支持已确认双人同框素材；过肩机位禁止提交该路径，不静默降级。

CPU准备器生成原全画面参考，保留其文件哈希，再裁切锚点、角色掩码和参考视频，音频保持不变，参考视频的静音音轨保留。模型图明确使用sageattn并保持区域原生高度；回贴使用原实验相同的1.4倍人脸椭圆与平滑边缘配方。正式服务和独立CPU运行时各有一份部署配方，启动任务时逐字节校验一致，测试同时核对实验配方，防止三个路径漂移。

每个新外部任务提交前验证`/duocast-benchmark/identity`中的隔离Sage扩展treeHash和成功调用计数。完成后必须观察到成功计数增长，缓存必须已有持久化Sage验证记录；缺少证据即拒绝，不回退SDPA。无法证明重启前已完成任务的Sage调用时，也不会把没有证据的任务当作合格结果。

ROI核心回贴后恢复原全画面大小，登记原生窗口产物；之后预览与整片均采用Lanczos、轻锐化0.45和CRF16导出。编码前裁切区域外像素保持原参考；有损编码后不宣称像素相等。

## 整期合成与正常导出

1. 窗口候选保存`windowArtifacts`，绑定原生核心的登记ID、文件哈希、依赖和绝对帧区间。
2. `GET expert-video/assembly-plan`从实际采用账本重建覆盖，拒绝缺口、重叠、不同快照、过期输入或损坏文件。缺失时返回数量，页面指导用户补齐剩余对话。
3. `POST expert-video/assemble`用幂等标识提交CPU任务，冻结采用版本；合成只读取已采用核心与原PCM母轨，不调用模型。
4. Worker逐窗检查帧数/25fps，验证母轨采样率、样本数、单声道PCM16；拼接后检查整期帧数、分辨率、时长和解码。完成前再次检查采用版本及原文件身份。
5. 合成结果是待审候选，不自动覆盖正式成片。已登记完整产物可以按原任务恢复，拒绝覆盖身份不一致的旧文件。
6. 完整观看并确认后，`POST expert-video/assemblies/{jobId}/adopt`经ProjectStore和正常输出版本机制更新导出。旧输出历史保留；重复采用同一当前成片返回原版本。

散列检查在异步任务中放入工作线程，避免长片文件核验阻塞页面轮询。API只接受计划/任务身份，不接受客户端媒体路径。

## 部署要求与明确未完成项

没有重启现有正式服务，也没有改动其他项目的GPU服务。正式执行器仍默认未启用。

启用Sage区域路径需要服务器配置：`DUOCAST_EXPERT_PREPARATION_ROOT`、实际核验的`DUOCAST_EXPERT_ENGINE_FINGERPRINT`、`DUOCAST_EXPERT_PROFILE=expert-sage-roi-v1`、`DUOCAST_EXPERT_SAGE_TREE_HASH`。配置的Comfy引擎必须实际加载原隔离Sage包及身份探针；单纯填写摘要不会自动安装扩展或证明兼容。

CPU运行目录需部署更新后的`prepare_expert_motion.py`、`expert_roi_media.py`、`expert_roi_geometry.py`，以及原有`motion_worker.py`、`motion_audio_cache.py`和含cv2/numpy的venv。几何部署文件必须与服务端配方一致。缺少文件或身份校验失败时任务在提交模型前停止。

旧候选如果没有原生窗口登记证据，不能仅凭预览MP4被纳入整片复用；页面/接口会要求重新生成相应候选。

目前整片合成只复用已经采用的窗口；**一键规划并生成所有剩余窗口的续算入口尚未实现**，用户仍需选择剩余对话生成并采用。真实部署后的专家调用、端到端长片耗时和本次新集成路径的角色画面质量，仍需下一轮实测，不能用本次色块测试替代。
