# 一键续算剩余内容

日期：2026-10-28。状态：代码接通并完成无模型验证，正式服务未启用，无新的真实推理或角色质量采用记录。

## 用户流程

在视频工作区采用预览后，点击“检查剩余内容（不生成）”。页面显示可保留的已采用片段数，以及还需生成的数量。点击“一键生成剩余内容”创建幂等任务；结果以“整期续算”候选显示，完整审看并采用后，继续整期覆盖检查、合成和正常导出。

内容已经完整时不显示生成操作，提示直接合成；服务端同样拒绝零缺失窗口的生成请求，不产生GPU任务。未配置执行器时仅开放规划。

## 复用规则

- 从服务端冻结的整期计划选择全部窗口，保持原始绝对帧、母轨采样区间和上下文。
- 按实际采用账本寻找原生核心，重验来源任务、工程依赖、整期快照、登记身份与媒体哈希。不能只因存在预览MP4就判为可复用。
- 保留用户采用的局部重做结果，包括该轮独立种子与依赖。原参考内容、几何、上下文和时钟必须与整期基线一致，只有采样身份允许改变。
- 续算计划冻结采用修订号。提交前或任务完成后采用版本已变化时，拒绝旧计划提交或覆盖新选择，要求重新规划。
- CPU准备只处理待生成窗口，模型循环直接跳过复用窗口；复用全画面原生核心不会再次进行区域回贴。
- 最终审看片按原位置组合复用与新生成核心，使用完整母轨；不把不连续缺失窗口直接串接成错位短片。

## 接口与实现

`POST /api/projects/{id}/expert-video/continuation-plan`由服务端选择整期，返回`reuseSelectionRevision`、`reuseWindows`、`reusedWindowCount`、`generateWindowCount`。不允许客户端指定局部turnIds或运行路径。

既有`generate`执行该持久化计划，仍沿用原任务幂等、取消、恢复和候选采用机制。`expert_continuation`负责冻结与校验复用；专家适配器只对缺失窗口调用采样器，最终原生窗口登记与整期合成机制保持一致。
