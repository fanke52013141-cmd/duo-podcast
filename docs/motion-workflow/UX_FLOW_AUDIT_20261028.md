## 用户操作链逐项结论

1. 配音就绪→旧样片：服务端区间与前端统一，修复开头角色和短脚本限制。请求失败或版本不符时不使用旧计划。真实屏幕操作待浏览器可用后复验。
2. 样片播放→检查→采用：既有入口保留，检查未齐时有正确提示。现有真实/模拟产物区分不改变；没有替用户勾选或登记通过。
3. 新两轮预览：规划可选四完整话轮且保留原时钟/种子，纯规划接口测试通过；页面和执行缺失。此项是当前最关键断路。
4. 预览采用→整期复用：目前没有正式执行与复用闭环，不能承诺已预览内容不会重算。必须用实际调用计数验证。
5. 新单轮重做→候选对比/采用/回退：规划已有上下文失效范围，候选执行与状态持久化尚缺；旧页面的“从时间重做后续”不能替代它。
6. 当前成片/旧候选/版本恢复：保留原页面能力；本次不操作真实工程采用记录。新话轮候选仍需单独接入版本模型。
7. 导出及状态：示意区间不再冒充实际模型进度；编码固定项清晰。真实媒体生成/下载未执行。
