# 专家视频提速：已验证结果与剩余验收

更新：2026-10-28。当前结论：同框黄瓜/茄子案例已完成一次真实两分钟冷模型测试，视频流程47分35秒；长片效果审看与重复稳定性未完成，不能声明正式产品已上线。

## 保留路线

原已采用动作素材 → 同一母轨与A/B分轨 → 原像素尺度的双脸联合区域 → Wan/InfiniteTalk专家生成、SageAttention → 按逐帧脸部轨迹柔边回贴原动作画面 → 导出 → 完整解码及音轨核对。

模型仍是Wan2.1 I2V 14B fp8与InfiniteTalk Multi fp8，沿用LightX2v LoRA、4步调度从第2步开始（实际两次去噪）。原图864×480，当前联合区域576×336，脸部不缩放；交付1280×720/25fps。只在独立实验环境显式选择候选，未改变正式项目入口或共享依赖。

用户已分别确认Sage全画面10.8秒、区域10.8秒候选效果；采用记录绑定对应媒体摘要，不能扩展为两分钟长片已通过。

## 实际耗时及口径

| 内容 | 实测 | 范围与限制 |
|---|---:|---|
| 10.8秒SDPA全画面对照 | 590.0秒 | 引擎启动至所有窗口检查；无最终拼接 |
| 同内容Sage全画面 | 451.2秒 | 同口径单次A/B，墙钟减少23.5% |
| 10.8秒Sage区域版 | 260.9秒 | 输入就绪至回贴导出及音轨核对；区域准备3.3秒另计 |
| 30秒区域版 | 12窗口完整完成 | 750帧及音轨检查通过；原最终检查接口误用后修复核对，不报连续成功总时长 |
| 真实120秒区域版 | **2854.9秒，47分35秒** | 含母轨/参考/区域准备、启动、47窗口、回贴导出、媒体及音轨检查；配音合成另计 |

两分钟测试不是旧短片循环：16轮新配音、112.64秒真实配音单元跨度，加自然接话停顿形成120秒母轨；47个窗口实际采样，最终3000帧。动作素材本身按已采用动作包复用。

冷模型指新启动独立模型进程；操作系统和文件缓存可以是暖的。不能把原专家10.8秒线性估算的两小时当作真实两分钟对照，也不能由这一次47分35秒证明任意内容均一小时内。

## 未采用的开关

- 38→36交换块：没有明确收益。
- 非阻塞传输：匹配双窗口差异约0.13%，不足以认定提速。
- 权重预取：第二窗口明显变慢并伴主机内存压力，中止，未采纳。
- 新文本条件缓存：曾实测命中且输出一致，但冷双窗口整轮更慢；诊断复跑的快窗口由框架缓存命中，不能归功于新模块。保持实验选项。

文本重复加载与主机32GB内存压力仍值得调查，但先保持已验证路线，避免将未经整体验证的新开关叠加到长片成绩。

## 复核与后续顺序

1. 审看交付的两分钟成片，确认口型、嘴唇稳定、融合、倾听和接缝。人工问题已发出，当前仍待回复。
2. 质量通过后完成暖模型及重复稳定性验证。复用条件可以，实际采样不能命中旧结果；每轮单独计时、保留失败，不能只报最快值。
3. 同框与过肩分别验收；当前两分钟成绩只覆盖同框。未证实的机位不得沿用此成绩。
4. 候选与稳定性通过后再接正式API/UI，补运行时身份、GPU互斥、取消恢复及旧项目回归。当前仍是实验链路。

本轮无需重新生成已经完成的冷模型批次。继续工作先检查原始结果；如果任务仍存活，只续查原ID。临时暂停的8101/8200/8202已恢复且健康检查200。
