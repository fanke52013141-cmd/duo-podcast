DESIGN SYSTEM & PAGE PLAN

双声播客工坊 · UI 设计系统与页面规划

本文档把 01 §0.5 的全局设计语言扩展为完整的设计令牌与组件体系，给出五阶段工作台的整体页面设计（应用壳蓝图、分区规格、布局模式、响应式行为），并规定其到 Tailwind / Radix 的落地映射。色彩基调继承 01 §0.5 权威定义：焦糖品牌色、A 青蓝 / B 珊瑚粉双角色功能色；本档在其上补充满足对比度 ≥4.5:1 的文字深色阶。

版本 v1.02026-09-10依据：01 §0.5 / §1 / §13目标栈：React 18 + Tailwind + Radix 令牌前缀 --dc-状态：方向稿（待逐屏高保真）
权威关系：基础色相以 01 §0.5 为权威，本档仅做「派生色阶 + 使用规则」的扩展，不改变既定色相；组件行为规则以 01 §1 / §13 为权威，本档负责视觉规格与状态呈现。本文档内所有样例均使用同一套 --dc- 令牌渲染，即 tokens.css 的可视化草案。

0设计定位与原则

产品性质本地专业创作工作台（不是消费级内容 App）：高信息密度、可逆操作、版本可见
视觉基调安静的中性底 + 焦糖品牌点缀；色彩主要用于「说话人身份与状态」而非装饰
参照系专业工具（DAW / 剪辑软件）的信息组织 + 消费级产品的可读性与温度
首版主题亮色单主题；暗色主题列为后续候选（不在首版承诺）
六条设计原则（评审 UI 时的裁决依据）
#原则落地规则反例（禁止）
P1状态由产物推导完成态永远来自版本与任务状态（01 §13.1 七态），UI 不手写完成标记用「下一步」点击次数推断进度
P2色彩即语义A 青蓝 / B 珊瑚粉只表示说话人；橙=待确认/已过期；绿=已就绪；红=失败。颜色永远伴随文字标签（01 §0.5 无障碍要求）用品牌色标注说话人；仅用色点不带文字
P3高密度但不局促清单/表格用紧凑行高，表单/卡片用舒适留白；同级元素间距一致大面积空白装饰；卡片固定高度致内容滚动
P4图标 + 文字的一致操作同类操作按钮统一「图标 + 文字」样式；纯图标按钮仅限播放控制等高频紧凑位同类操作一处带字一处只有图标
P5可调优先校验只提示不硬拦（空数据与确认点除外，01 §13.3）；破坏性操作需确认弹窗打断每一步编辑
P6所见即可信能力门控（01 §1.6.4）：不支持的参数不显示；无测速数据不显示编造预估显示无效参数选项；假进度条
