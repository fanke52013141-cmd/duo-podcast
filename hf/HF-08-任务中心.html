四边界说明

  • 风格基准：全部视觉来自 workspace-ui v0.2 基线 + duo-shell.css 组合扩展；状态用「圆点 + 文字 + 徽章」多通道，无纯色点。
  • 统一视图：本地与 API 任务同列表呈现，不按引擎分栏。
  • 进度不撒谎：节点进度映射为阶段进度，不当作精确剩余时间；ETA 一律标注「同规格历史实测」。
  • 取消可验证：「正在取消」与「已取消」分开；无定向取消能力时显示「取消待生效」。
  • 费用诚实：待核实任务不自动重试；再次生成需二次确认并提示可能重复计费。
  • 重连权威：状态以服务端快照为准，事件带序号补发，不依赖浏览器历史进度。
