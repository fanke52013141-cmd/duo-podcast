四边界说明

  • 风格基准：全部视觉来自 workspace-ui v0.2 基线 + duo-shell.css 组合扩展（B 发言人色调 / 紧凑图标）；不复制色值，与 HF-00 / HF-01 同族。
  • 三层对象：Line / Turn / Unit 三层在数据层存在；用户默认编辑自然话轮（Turn），句子与单元由系统派生并在需要的位置显示。
  • 按钮语义：brand 橙 = 本视图唯一品牌动作「确认脚本」；primary 深灰 = 常规主操作（下一步）；secondary = 重新生成 / 版本 / 改写等工具操作；ghost = 拒绝 / 忽略等轻操作。
  • 状态双通道：徽章均「色调 + 文字」；待确认用 warning 橙，已确认用 success 绿；T 稳定 ID 用等宽字。
  • 版本语义：编辑 → 新草稿 R9 不覆盖已用 R8；任务结果到达时草稿已变化 → 只加入历史并标记所属版本（01 §13.2）。
  • 质量提示边界：长度与占比本地计算；语义判断标注「AI 建议」不作为事实保证；不接受不存在的引用。
  • 确认后自动配音：仅导航至阶段③；自动配音可在模板关闭。
  • 本屏无 TimelineBar：配音确认后才常驻（05 §1.5），本阶段只有文字产物。
  • 键盘：Ctrl+Z 撤销；Space 播放（无音频时禁用）；1–5 切阶段。
