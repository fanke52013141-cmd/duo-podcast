四边界说明

  • 风格基准：本屏全部视觉来自 workspace-ui v0.2 基线（vendor/workspace-ui/ 原样引入 tokens.css + components.css + components.js），页面仅做布局组合，不复制色值；与 HF-00 共用同一套组件与令牌。
  • 按钮语义：primary 深灰 = 产品常规主操作（下一步）；brand 橙 = 每视图仅一处品牌动作（本视图为「生成对话 / 解析脚本」）；secondary = 次操作（导出 / 资产抽屉）；ghost = 生成中取消等轻操作。
  • 状态双通道：所有徽章均「色调 + 文字」，无纯色点（基线 SPEC）；服务状态用 wu-badge 文字呈现（正常 / 异常 / 未配置），不用颜色圆点。
  • 切换保留：切换起步方式时保留已输入内容（话题 ↔ 文章 ↔ 脚本互切不丢字）。
  • 校验口径：文章 ≤8,000 字，超出 warning 提示不硬拦；话题建议 ≤200 字；「大约 N 分钟」是偏好不是承诺。
  • 两次生成：第一次内容结构（核心问题 / 主要观点 / 必要事实 / 段落目的 / 双方职责），第二次结构化话轮（稳定 ID / 说话人 / 显示与朗读文本 / 意图 / 语气 / 来源引用）；简单输入（纯话题）第一次自动通过。
  • 引用核对：文章中的事实与模型补充的例子分开标识；来源锚点由程序按原文位置核对，不接受不存在的引用。
  • 已有脚本：只做结构解析与校验，不默认改写；也不强制再生成（首版低成本能力）。
  • 角色边界：A / B 都可替换，不把 A 永久固定为主持人；角色意图覆盖解释 / 追问 / 举例 / 质疑 / 总结——不把所有 B 台词写成「对，你说得对」。
  • 视觉准备：与内容工作独立保存，可随时回来；不做强制顺序。
  • 失效规则：改起步输入 → 生成新候选脚本，不影响已确认版本直到重新采用。
  • 完成条件：本阶段无确认点；脚本在阶段②「生成 → 编辑 → 确认」收口；视觉准备产物直接流向阶段④。
  • 导航与保存：下一步仅导航，缺失前置时目标页顶部 warning 提示；2s 防抖自动保存；Ctrl+Z 撤销；1–5 切阶段。
  • 服务断开：只禁用依赖该服务的操作（生成对话 / 解析脚本），编辑、播放已有素材不受影响。
  • 长文本：输入框高度自适应内容（最小 220px，可纵向拉伸），不设固定高度、不截断。
