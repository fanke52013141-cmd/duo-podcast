四边界说明

  • 风格基准：全部视觉来自 workspace-ui v0.2 基线 + duo-shell.css 组合扩展；能力状态行用「圆点 + 徽章文字」双通道，无纯色点。
  • 仅四块：文本 API / 图片 API / 本地引擎 / MiniMax 语音；不增加产品账号系统。
  • 凭据边界：机器级密钥库引用；工程只引用配置 ID；打包工程不含 API 密钥。
  • 能力边界：各能力分开登记；连接成功不代表具备人物一致性或多参考图能力；多参考图编辑不支持时同框图走上传替代。
  • 费用口径：付费试听与只读连通检查区分；测试按钮标注是否产生费用；缺价格配置时展示用量不伪造金额。
  • 离线影响：某一服务离线只影响需要它的操作；用户仍可编辑和播放已有素材。
